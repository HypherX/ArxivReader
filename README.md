# ArxivReader · 论文阅读与知识网络

一个本地运行的论文工作台：把想读的论文收进来，读完能沉淀成一张属于自己的方向树与论文图谱。

它解决三件具体的事：

- **读得动**：内嵌 PDF 预览 + 就论文提问，全文自动进上下文，回答带推理过程可折叠。
- **读得快**：两个技能——**快速总结**（速览 Insight/贡献/结论）与**深度精读**（动机、缺陷、创新、方法、实验、局限、可复现要点）。所有数字都标注来源（页码/表号），不给"看起来很像"的结论。
- **连成网**：每篇论文自动归入方向树（如 `LLM → RL → Agentic RL → Credit Assignment`），同一方向下的论文自动提炼互相关系（改进/基线/对立/互补…），并沉淀成分方向的论文图谱与阶段性综述。

再往外一层：**从 arXiv 里批量挑论文**。按日期/分类/关键词检索 → 模型读标题与摘要预筛 → 对过线论文跑快速总结复核 → 落进"待读缓冲区"，你决定哪些值得下载全文、正式入库。

## 功能一览

### 1. 论文库

- 粘贴 ArXiv 链接或 ID（如 `2401.12345`）入库：自动抓元信息、下载 PDF、抽取全文并缓存。
- 嵌套文件夹分类；支持**自动归档规则**（按分类/关键词/作者/标题匹配，priority 越小越先）。
- 内嵌 PDF 预览；正文抽取失败可一键「重抽全文」，界面会明确提示当前是否已入上下文。

### 2. 两个阅读技能

| 技能 | 定位 | 输出重点 |
|---|---|---|
| 快速总结 | 30 秒判断这篇值不值得读 | Insight、贡献、关键结论与数字、**解决了什么**、**未来展望** |
| 深度精读 | 读一篇等于读透一篇 | 动机与背景、已有方法的缺陷、创新点、方法细节、实验设置与结果、局限、可借鉴之处、复现要点 |

两个技能都由知识网络 pipeline 生成，产物直接显示在右栏的「🧾 快速总结」「📖 深度精读」页签里（也能一键复制 / 新窗口另存为 `.md`）。

两个技能都遵循**格式契约**：每个数字必须能溯源，写作 `[p.3]`（正文页码）、`Tab.2`（表格）、`（推算：…）`（由文中的数据算出）、`（抽取缺失）`（原文没给）。因此拿到一份笔记时，你能一眼看出哪些是论文原话、哪些是推算。

### 3. 对话问答

- 就当前论文提问，实时流式输出；推理模型的思考过程单独折叠展示，不干扰正文。
- 上下文策略：全文过长时自动压缩并声明省略了哪些部分；正文缺失时自动降级为"标题+摘要"模式并提示。
- 多会话管理，历史消息落库，推理内容可回看。

### 4. ArXiv 检索与智能筛选

四步流水线，全程只处理标题与摘要（不下载全文，成本可控）：

1. **批量检索**：日期范围 + 多个 arXiv 分类 + 关键词（AND/OR）。
2. **方向树预筛**：模型读你的方向树，给每篇候选打分并建议归属路径，低于阈值的直接丢弃。
3. **快速总结验证**：对过线论文跑快速总结，再复核"是否真的属于该方向"。
4. **写入待读缓冲区**：命中的论文进入缓冲区，你可以逐条预览、补跑总结、**加入详细阅读**（下载全文并跑完整知识网络流程）或丢弃。

检索在后台异步执行：页面可随时关闭或中断，已处理的结果不会丢。

### 5. 知识网络

- **方向树**：模型自动判断论文归属，可多归属（一篇论文同时属于主方向与交叉方向），新方向自动长出。
- **方向树 = 左侧文件夹**：带 🧭 前缀的文件夹就是方向节点，计数 = 该方向下直接挂载的论文数。
- **局部论文图谱**：同一方向下的论文会自动提炼关系（`improves` / `baseline_of` / `contradicts` / `complements` / `cites` / `extends` / `applies` / `uses`），带强度与人类可读理由。
- **图谱沉淀成 Markdown**：每个方向节点对应一份 `GRAPH.md`（含 Mermaid 关系图、论文清单、关系明细、最新综述），落在 `data/knowledge/<方向路径>/GRAPH.md`，可直接阅读、可提交进笔记库、可被任何 Markdown 工具渲染。
- **阶段性综述**：某个方向下论文数每增加 5 篇（可配置），自动生成一版综述，回答"这个方向大家在做什么、还有哪些没解决"。

## 安装与启动

### 环境要求

- Python 3.9+（开发环境实测 3.9.6）
- 可访问 arXiv 与你的 LLM 服务（OpenAI 兼容接口）

### 安装

建议把虚拟环境建在**项目目录之外**（保持项目目录干净，便于打包与备份）：

```bash
python3 -m venv ~/venvs/paper_reader           # 路径可自定，只要不在项目目录里
source ~/venvs/paper_reader/bin/activate       # Windows: %USERPROFILE%\venvs\paper_reader\Scripts\activate
cd paper_reader
pip install -r requirements.txt
```

（不想用虚拟环境也可以，直接用系统 Python 装依赖；本项目的依赖都在 `requirements.txt` 里。）

### 配置

首次启动时读取 `config.py` 的 `LLM` 节作为默认值，之后全部以网页「设置」为准（写入数据库，不回写文件）。

```bash
cp config.example.py config.py     # 可选：不创建也能用，直接走网页设置
```

两种配置方式，任选其一：

1. **网页配置（推荐）**：启动后在右上角「设置」里填 Base URL / API Key / 模型名，点「测试连接」确认可用，再保存。未配置时顶栏「设置」会显示为「⚠ 设置」，相关功能会明确提示先去配置，不会出现莫名失败。
2. **文件配置**：把 `config.example.py` 复制为 `config.py` 并填入 `base_url` / `api_key` / `model`，作为**首次启动**的默认值。`config.py` 已在 `.gitignore` 中，不会被提交。

> 支持的模型：任何 OpenAI 兼容接口。采样参数（temperature / max_tokens / top_p）留空 = 沿用服务端默认值；`reasoning_effort` 可填 `low`/`medium`/`high`/`max`，推理型模型建议 `max`（更慢，但更少幻觉）。

### 启动

```bash
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

浏览器打开 <http://127.0.0.1:8765> 即可。首次启动会自动建库、建 Inbox 文件夹并打印当前可用的技能与工具清单。

> 端口被占用时换一个即可（`--port 8770`）。深度精读一次可能耗时数分钟，属正常现象。

### 运行测试

```bash
cd paper_reader
python3 -m pytest -q          # 全部离线：不联网、不调用真实模型
```

## 使用指南

### 顶栏

- 中间输入框：粘贴 ArXiv 链接或 ID → 选择目标文件夹（或留「自动归档」按规则走）→ 点「添加」。
- 右侧按钮：**ArXiv 检索**（`⌘K` / `Ctrl+K` 直接打开）、**归档规则**、**设置**。
- 面板开关：可隐藏/显示四个栏位，栏宽可拖拽，布局自动记忆。

### 左栏 · 文件夹

- 「全部论文」显示全库；下面是嵌套文件夹树。
- 带 **🧭** 的是方向文件夹：点它会在右侧打开该方向的**论文图谱**。
- 文件夹行悬停出现 `＋`（新建子文件夹）`✎`（重命名）`🗑`（删除）；右键可打开完整菜单。
- 🧭 文件夹是知识网络的镜像：重命名会同步改名方向节点与图谱文档；删除它等于删除该方向节点（论文与 PDF 不删，子方向上移一层）。

### 中栏 · 论文列表

- 搜索框按标题/摘要/作者过滤；卡片上标注分类、所在文件夹、是否截断、是否缺正文。
- 悬停出现 `📁`（移动）`🗑`（删除，连带删除本地 PDF 与对话记录）。

### 预览区

- 点论文卡片：显示 PDF。
- 点 🧭 文件夹：显示该方向的论文图谱——路径、论文数、关系边数、关系图例、关系图（节点大小区分主/次归属，边标签是关系类型）、论文卡片（点击可打开 PDF）、以及折叠的 `GRAPH.md` 全文。
- 工具栏（选中论文时）：**🧠 知识网络**（跑五步并实时显示进度，可随时终止）、移动、重抽全文、删除、隐藏此栏。
- 图谱工具栏：打开 md、刷新、**重建文件**（把方向树重新同步成文件夹并重写所有 `GRAPH.md`）、**删除方向**。

### 右栏 · 对话 / 阅读产物

右栏顶部有三个页签，随时切换：

| 页签 | 内容 |
|---|---|
| 💬 对话 | 与论文对话，Enter 发送、Shift+Enter 换行；流式生成中按钮变为「■ 停止」（Esc 也可以） |
| 🧾 快速总结 | 由知识网络生成的速览笔记（洞察/贡献/结论/未来展望） |
| 📖 深度精读 | 由知识网络生成的完整精读笔记（动机/方法/实验/局限/可复现要点） |

说明：

- 页签上的角标就是产物字数；未生成时显示「未生成」，点一下可直接触发生成。
- **跑完「🧠 知识网络」后会自动打开刚生成的产物**，不用再去翻找。
- 每份产物都能：**⧉ 复制**（全文 Markdown）、**↗ 新窗口**（可直接另存为 `.md`）、**↻ 重新生成**（只重跑这一步，覆盖旧内容）。
- 产物里的数字都带来源标注（`[p.N]` 页码 / `Tab.N` 表格 / `（推算：…）` / `（抽取缺失）`）。
- 对话区顶部还会显示「知识网络」进度面板（五步实时状态），历史消息与推理内容均自动保存。

### 随时终止正在跑的任务

| 位置 | 按钮 | 效果 |
|---|---|---|
| 对话栏发送按钮 | **■ 停止**（流式中出现，Esc 同效） | 立即停止本次生成；**已生成的部分会保留并标记「已被终止」一起落库**，刷新会话也在 |
| 知识网络进度面板 | **■ 终止** | 停止当前步；当前步记为「已被用户终止」、整轮记 `cancelled`；**已完成的产物保留**，下次运行从断点继续 |
| ArXiv 检索页 | **中断检索** | 当前批次结束后停止，已写入缓冲区的结果不丢 |

终止是服务端协作式的：不只是断开浏览器连接（那样模型会继续输出到底、白烧 token），而是显式通知服务端在下一个事件/步骤处停止，并顺带关闭底层模型连接。

### ArXiv 检索页

表单字段：

| 字段 | 含义 |
|---|---|
| 日期从 / 到 | 按 arXiv 提交日期过滤，留空表示不限 |
| 最多条数 | 本轮最多拉取多少条命中结果 |
| 预筛阈值 | 方向树匹配分低于此值的候选直接丢弃（默认 0.55） |
| 复核上限 | 本轮最多对多少篇跑快速总结（控制成本） |
| 分类 | 勾选常用分类，或填自定义分类（逗号分隔） |
| 关键词 | 空格/逗号分隔；AND = 全部命中，OR = 任一命中 |

点击「开始检索」后：左侧显示四步状态、进度条与实时日志；右侧是缓冲区列表，每条带匹配分与复核状态，可：

- **预览**：展开摘要、快速总结（含"解决了什么 / 未来展望"）、归属复核理由。
- **补跑总结**：对这一篇补跑快速总结与归属复核（不下载全文）。
- **加入详细阅读**：下载全文、入库，并自动跑完整知识网络流程（快速总结 → 方向树归属 → 深度精读 → 局部图谱 → 阶段综述）。后台执行，可关闭窗口，卡片上会显示处理状态。
- **丢弃**：不感兴趣，保留记录但不再参与流程。

「中断检索」在当前批次结束时停止，已写入缓冲区的结果保留。

### 设置与归档规则

- **设置**：Base URL / API Key / 模型 / 采样参数；「测试连接」会先保存再发一次真实请求校验。
- **归档规则**：为入库论文指定自动归属的文件夹；命中规则才生效，都不命中则进 Inbox。

## 数据与配置文件

| 路径 | 内容 |
|---|---|
| `data/library.db` | SQLite 数据库：论文元信息、文件夹、对话、缓冲区、方向树与图谱边、综述、运行账本 |
| `data/pdfs/` | 下载的 PDF 原文 |
| `data/knowledge/<方向路径>/GRAPH.md` | 每个方向节点一份论文图谱文档 |
| `config.py` | 首次启动的默认配置（已被 `.gitignore` 忽略，不会入库） |

整个 `data/` 目录即全部数据，直接拷贝即可迁移或备份；删除它相当于恢复出厂设置（首次启动会自动重建）。

## 常见问题

**Q：一定要联网吗？**
入库论文、检索、跑技能需要访问 arXiv 与你的 LLM 服务；浏览已下载的 PDF 与浏览已生成的知识网络不需要。

**Q：为什么深度精读很慢、很贵？**
精读会带着论文正文（按预算裁剪后的上下文）做多轮推理。`reasoning_effort=max` 下单次请求可能几分钟；把模型的推理强度调低、或把 `HARNESS.skill_context_tokens` 调小可以明显降低成本。

**Q：提示"未抽取到正文"怎么办？**
多为扫描版/图片型 PDF。界面上会提示当前只有标题与摘要可用，可点「重抽全文」重试。

**Q：论文数字后面的 `[p.3]`、`（推算：…）` 是什么？**
页锚点与来源标注：`[p.N]` = 正文第 N 页、`Tab.N` = 表格、`（推算：算式）` = 由原文数字算出、`（抽取缺失）` = 原文未提供。这是为了让笔记里的每个数字都能回查。

**Q：想手工整理方向树？**
🧭 文件夹支持右键重命名与删除；删错了删掉的只是"归属与图谱"，论文本身不会丢。「重建文件」可把方向树重新同步成文件夹与图谱文档。

**Q：密钥存在哪里？**
只存在 `config.py`（若你填了）与 `data/library.db`，接口返回时只给打码预览。发布/分享本项目时请勿附带 `config.py` 与 `data/`。

**Q：能换别的模型吗？**
可以，任何 OpenAI 兼容接口都行，在「设置」里填 Base URL 与模型名即可。
