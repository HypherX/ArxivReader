# 📚 ArxivReader

**在你自己电脑上跑的论文阅读器** —— 收 arXiv / 本地 PDF，读原文、划词翻译、问答精读，再把一堆论文长成方向树与关系图谱。


[中文](README.md) · [English](README.en.md)

## ✨ 功能

### 📥 收集论文

| | |
|---|---|
| 🔗 **arXiv 一键入库** | 粘贴 arXiv 链接或编号（如 `2401.12345`），自动下载 PDF 并抽取全文。 |
| 📤 **本地 PDF 上传** | 直接把电脑里的 PDF 拖进来；按文件内容指纹去重，重复上传会提示已在库中。 |
| 🧲 **引文挖掘** | 模型会自动阅读 related work 和 reference 并检索相关工作，根据摘要给出相关度（低相关度直接过滤）。选中的论文只加入文献库（全部论文），之后再自行决定要不要总结、分类、精读或抽取关系。 |

### 📖 阅读与翻译

| | |
|---|---|
| 🖍 **划词翻译** | 选中任意一句或一个词，点浮出的「翻译」，译文就出现在阅读器右侧的译文栏里，可连续翻多段并回看，也能一键复制。 |
| 🌐 **全文翻译** | 整篇 PDF 一键译成中文：中英对照（同页左右 / 交替页）或纯译文版，公式、图表、排版原位保留，译完在阅读器里一键切换原文 / 对照版。引擎首次使用时按需下载（见下文「全文翻译引擎」），翻译用的模型可单独配置。 |
| 🔎 **全文检索** | 在 PDF 里查找关键词，显示命中总数并逐处跳转定位。 |
| ⧉ **选中即复制** | 文字层是真实文本，复制术语、符号、段落不再需要 OCR 或截图。 |
| 🌐 **中英界面** | 界面可整体切换中文 / 英文，译文跟随应用的输出语言设置。 |

### 🧠 理解与整理

| | |
|---|---|
| 💬 **全文问答** | 用户可就当前论文进行任意内容的提问。 |
| 🧩 **预设四个独立 AI 动作** | 快速总结 / 自动分类 / 深度精读 / 论文关系。 |
| 📝 **阅读笔记** | 快速总结与深度精读都保留历史版本，可复制、可导出 Markdown、可开独立窗口专注阅读。 |
| 🌳 **方向树** | 让模型把论文归入唯一分类方向，自动长出层级文件夹；也可以自己建子文件夹、手动移动归类。 |
| 🕸 **关系图谱** | 流程图式的有向图：分层排布，箭头带关系类型与证据强度，悬停高亮相关边，点节点直接打开那篇论文。单篇论文看它自己的关系邻域，方向文件夹看整张子图。 |
| 📄 **文件夹综述** | 把一个文件夹下的所有论文汇总成一份综述报告，分批取证、可续跑、历史可回看。 |

> 所有 AI 能力都由**你自己配置的模型**驱动（兼容 OpenAI Chat Completions 接口的服务均可），不注册账号、不需要服务器。

## 🚀 使用方式

### 方式一：下载桌面应用（推荐）

到 **[Releases](https://github.com/HypherX/ArxivReader/releases)** 下载对应平台的压缩包：

| 平台 | 文件 |
|---|---|
| 🍎 Apple Silicon（M 系列） | `ArxivReader-macOS-arm64.zip` |

- **macOS**：解压后把 `ArxivReader.app` 拖进「应用程序」，双击打开。若提示「无法验证开发者」，到 **系统设置 → 隐私与安全性** 点「仍要打开」即可，无需关闭系统安全功能。
- **Windows**：解压后保留文件夹内全部文件，双击 `ArxivReader.exe`。

> 构建包未做签名与公证，首次启动的系统提示属于正常现象。每个压缩包都附带 `.sha256` 校验文件。
> 目前我们只构建了 M 系列芯片的 Mac 版本，其他平台可以自行构建。

### 方式二：从源码运行（浏览器打开）

需要 Python 3.12 或更新版本：

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务，然后浏览器打开 http://127.0.0.1:8765
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765

# 或者：开一个桌面窗口（需要 pywebview，见 requirements-build.txt）
python desktop.py
```

## ⚙️ 首次配置模型

首次启动会自动打开「设置」，填三项即可：

1. **Base URL** — 模型服务的 API 地址（兼容 OpenAI Chat Completions 接口的都行）。
2. **API Key** — 你的密钥。
3. **模型** — 模型名称，比如 `gpt-4o`、`deepseek-chat`。

点「测试连接」确认能用（会真实调用一次模型），再点「保存」。
**不配模型也能用**：管理论文、阅读 PDF、划词复制都照常，只是 AI 相关功能不可用。

## 🌐 全文翻译引擎（首次使用一键安装）

「全文翻译」由 [PDFMathTranslate](https://github.com/PDFMathTranslate/PDFMathTranslate-next)（pdf2zh_next）引擎驱动。它的依赖比较重（onnxruntime、版面分析模型等，约数百 MB），所以**故意不打包进主程序、也不在 requirements.txt 里**，而是首次使用时按需安装到独立目录：

1. 打开任意一篇论文，点阅读器工具栏的 **🌐 全文翻译**；
2. 在弹窗里点 **安装引擎**，安装日志实时可见，装一次以后一直可用。

安装时自动选择环境（按优先级）：

- **装了 [uv](https://docs.astral.sh/uv/)（推荐）**：速度最快，且会自动准备 Python 3.12，无需操心环境；
- **源码运行**：没有 uv 时直接用当前 Python（需 3.12+）创建环境；
- **桌面应用**：没有 uv 时会自动在系统里找 Python 3.10–3.13（包括 Homebrew、python.org 等常见安装位置；macOS 自带的 `/usr/bin/python3` 是 3.9，会被跳过）；实在找不到会提示你装 uv 或 Python 3.12。

国内网络可以在 **设置 → 全文翻译（PDF）** 里勾选「安装引擎时使用国内镜像」（清华源）加速。另外首次翻译时引擎还会联网下载版面分析模型与字体资源，属正常现象。

翻译用的模型**默认跟随主模型设置**，但全文翻译 token 用量大，建议在 **设置 → 全文翻译（PDF）** 里单独配一套便宜的服务——支持 OpenAI 兼容、DeepSeek、智谱 GLM、Gemini、SiliconFlow、Ollama（本地），以及 Bing / Google 免费翻译；QPS、源语言 / 目标语言、对照排版都可调。

引擎和译文产物都在数据目录的 `pdftranslate/` 子目录里，随数据一起备份即可；不需要时删掉这个子目录就完全卸载。

## 🗂 论文放在哪

新加入的论文默认只属于 **「全部论文」** 这个总目录——不会被自动塞进任何子文件夹。之后你可以：

- 点 **🗂 自动分类**，让模型把它归入方向树里的某个方向（同时生成对应的方向文件夹）；
- 或自己建子文件夹，用 **📁 移动** 放进去，也可以再移回「全部论文」。

「全部论文」始终展示库里的每一篇；选中某个文件夹时，会连同它的所有子文件夹一起统计。

## 📁 数据存在哪

| 运行方式 | 数据目录 |
|---|---|
| 桌面应用（macOS） | `~/Library/Application Support/ArxivReader/data/` |
| 桌面应用（Windows） | `%LOCALAPPDATA%/ArxivReader/data/` |
| 源码运行 | 项目目录下的 `data/` |

PDF、数据库、笔记全在这个目录里，**备份 = 复制整个目录**（备份前先关闭应用），换电脑同理。

两点需要知道：

- API Key 以明文存在本地数据库里，请不要把整个 `data/` 目录分享给别人。
- 「本地保存」不等于「完全离线」：下载 arXiv 论文需要联网；AI 功能会把论文内容发给你配置的模型服务商并产生费用，数据政策以服务商为准。

## ☁️ 云同步

点顶栏的 **☁️ 云同步**，可以把整个文库（PDF、数据库、笔记）备份到云端，并在换电脑后完整恢复。目前支持两种后端，任选其一：

| 后端 | 适合谁 | 配置方式 |
|---|---|---|
| **Google Drive** | 有 Google 账号 | 填入自己 Google Cloud 项目的 OAuth Client ID / Secret，点「连接」授权一次即可 |
| **WebDAV（坚果云等）** | 想要 Zotero 式自定义节点 | 填入服务器地址、账号、应用密码，点「连接」即可 |

以 **坚果云** 为例（Zotero 同款配置）：

1. 登录坚果云网页版 → **账户信息 → 安全选项 → 第三方应用管理 → 添加应用密码**，生成一个应用密码（不是登录密码）；
2. 在云同步窗口选 **WebDAV** 页签，服务器地址填 `https://dav.jianguoyun.com/dav/`，账号填坚果云邮箱，密码填刚生成的应用密码；
3. 「备份目录」默认 `ArxivReader`（网盘根目录下的文件夹名），可自定义，比如坚果云建议改成 `我的坚果云/ArxivReader`；
4. 点 **连接**，通过后 **上传** / **恢复** 一键同步。

其他 WebDAV 服务（Nextcloud、ownCloud、群晖等）同理，填各自的 DAV 地址即可。

几点说明：

- 上传会跳过内容未变化的文件；恢复前会把当前本地数据保留一份备份，恢复过程逐个校验文件哈希，失败不会动本地数据。
- 云端副本里**不含** API Key 和同步密码（这些只留在本机 `sync/` 目录，密码文件权限 0600）。
- 只允许 HTTPS 地址（本机测试除外），防止账号密码被明文窃听。

## ❓ 常见问题

<details>
<summary><b>上传的 PDF 没有作者、摘要信息？</b></summary>
本地 PDF 没有 arXiv 元数据，标题会取 PDF 自带的标题或文件名，可以直接改名。AI 问答和总结不受影响（全文已抽取）。
</details>

<details>
<summary><b>扫描版 PDF 无法提问？</b></summary>
扫描件没有文字层，抽不出文本，需要先用 OCR 工具处理。这类 PDF 依然能正常阅读，只是 AI 功能没有文本可用。
</details>

<details>
<summary><b>译文会重复花钱吗？</b></summary>
不会。译文按原文哈希缓存在本地资料库里，同一段第二次点开直接读缓存，不再调用模型。
</details>

<details>
<summary><b>长任务跑一半想停？</b></summary>
所有 AI 任务都能随时终止，已经生成的部分会保留并落库，不会白烧 token。
</details>

<details>
<summary><b>全文翻译提示「引擎未安装」？</b></summary>
这是正常的：引擎按需下载，点弹窗里的「安装引擎」即可，一次性。安装失败多半是网络问题——看弹窗里的日志确认原因，可在「设置 → 全文翻译（PDF）」开启国内镜像后重试。
</details>

<details>
<summary><b>Mac 提示应用已损坏 / 无法打开？</b></summary>
这是未签名应用的正常提示，按「使用方式」里的说明在「隐私与安全性」中允许即可。
</details>
