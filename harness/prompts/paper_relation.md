# 论文关系抽取（Paper Relation）

你要在**同一个细分方向节点**内，判断"新论文"与"该节点已有论文"之间的关系，输出可绘制成图谱的关系边。

## 关系类型（relation 只能取以下之一）

- `cites`：以对方的方法/结论为直接基础
- `extends`：在对方基础上做扩展（同思路、更大范围）
- `improves`：针对对方的具体缺陷做改进，并有对比或消融证据
- `contradicts`：结论/假设与对方冲突
- `complements`：思路互补，可组合使用
- `applies`：把对方的方法用到新场景/新模态
- `baseline_of`：对方是本文的对比基线（被本文比较或超越）
- `uses`：复用了对方的组件、数据或评测协议

## 硬性要求

- **只输出有证据的边**：依据来自新论文的深读笔记（对比实验、引用、批评、复现设置）。没有证据就不写。
- 每篇已有论文**至多一条**边，取关系最强的那一种。
- 理由必须具体到机制或实验（"新方法把对方的 variance reduction 换成 group-relative baseline"，而不是"效果好"）。
- `strength` 0.1~1.0：有直接对比实验的 ≥0.7；机制直接相关的 0.4~0.6；仅概念相关 ≤0.3。
- 如果与该节点下所有已有论文都没有实质关系，返回空数组（不要硬凑关系）。
- 引用页码或表号时用 `[p.N]` / `Tab.N`，且必须来自笔记中真实出现的内容。

## 输出格式（只输出 JSON，不要解释文字、不要代码块围栏）

```
{
  "edges": [
    {"other_paper_id": 12,
     "relation": "improves",
     "direction": "->",
     "strength": 0.8,
     "rationale": "<一句话说明关系，具体到机制/实验>",
     "evidence": "<笔记中的依据，如 §7 消融 / Tab.3 / [p.7]>"}
  ]
}
```

- `direction`：`->` 表示新论文指向对方（如新论文改进了对方）；`<->` 表示互补/互惠。
- `other_paper_id` 必须来自输入给出的已有论文 id。
