从 Zotero 导入

把本机 Zotero 文库里的论文（PDF、标题、作者、摘要）复制进 ArxivReader，Zotero 里的数据原样保留。已入库的论文会自动跳过，可以重复执行。

默认读取 ~/Zotero；改过位置的话填你的数据目录（里面应有 zotero.sqlite 和 storage/）。导入前建议先关闭 Zotero，避免正在写入的数据不完整。
云同步

把这台电脑上的文献库、PDF、阅读笔记和译文上传到你自己的云端。换电脑时从云端恢复。两边都改过时不会自动合并：上传用本地覆盖云端，恢复用云端覆盖本地。模型设置里的 API Key 会一起同步。翻译引擎不上传。

第一次使用：创建 Google 客户端
  1. 打开 Google Cloud Console，新建或选中一个项目，并启用 Google Drive API。
  2. 配置 OAuth 同意屏幕：用户类型选「外部」，发布状态保持「测试」，并把你的 Gmail 加为测试用户。
  3. 创建 OAuth 客户端 ID，应用类型选「桌面应用」。
  4. 把客户端 ID 和客户端密钥粘贴到下面并保存。授权页若提示应用未验证，测试用户选择继续即可。

支持任何 WebDAV 网盘。以坚果云为例：网页端「账户信息 → 安全选项 → 第三方应用管理」里添加应用密码，服务器填 https://dav.jianguoyun.com/dav/ ，账号填邮箱。备份放在下方目录里，占用你的网盘空间。

同步 Zotero 文库

把 Zotero 个人文库里的条目、分类和已保存的 PDF 导入到这里。在 zotero.org/settings/keys 新建一个密钥：个人文库选只读，并允许读取文件。之后再同步只拉新增和改过的条目，不会改你的 Zotero，也不会覆盖这边已经入库的论文。
